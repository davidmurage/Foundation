# AVLC Group — React (Vite) Corporate Redesign + Sanity CMS (Recommended)

This repo includes:
- **Web**: React + Vite + Tailwind + React Router
- **Studio**: Sanity CMS (authoring interface for Updates, Companies, Leadership)

## Run (Web)
```bash
npm install
cp .env.example .env
npm run dev
```

## Run (Sanity Studio)
```bash
npm run studio:dev
```

## Notes
- If Sanity env vars are not set, the web app automatically falls back to local JSON updates.
- For a KYC / due diligence context, keep copy **factual and verifiable**; avoid unapproved claims.
